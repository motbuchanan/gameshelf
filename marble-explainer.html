Marble Helpers

Why not a zillion marbles?

Every marble has to check "are we touching?" with every other marble, all the time. Think of it as a high-five between each pair.

3 marbles need 3 high-fives — every single moment
plenty of room — nice and smooth

Add one more marble and it has to high-five all the others. So the high-fives pile up faster and faster!

That's why the game stops at 18. More than that and there are too many high-fives to finish in time, so the game gets slow. The extra marbles wait safely in your collection.

Telling the game where "flat" is

A marble rolls downhill. So the game needs to know which way is flat. The neat part: flat is wherever you say it is.

tip left tip right
Flat is set to the middle

Hold the tablet however feels comfy — it doesn't have to be perfectly flat.

Tap Set flat. The game remembers that spot as "flat" for you.
3
Now tip it a little and the marbles roll that way. Tip it back to your flat spot and they stop.
